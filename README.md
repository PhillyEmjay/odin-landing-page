## Reflection
Very useful exercise. I spent a lot of time thinking about how to best write semantic HTML. I'm not confident that my CSS is efficient, but I think it's time to move on and save fine tuning for subsequent projects. As I move forward, I want to pay more attention to when and why `div` elements are necessary, learn the principles behind the issues that I had to fix in the beginning, and keep semantic HTML at the forefront of how I write pages.
